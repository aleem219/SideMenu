## UIKit Side Menu

A lightweight **side menu implementation in Swift using UIKit and UITableView**, built entirely with native iOS components.

### Technical Overview

* Developed using **Swift + UIKit**
* Implemented the menu using **UITableView**
* Drawer-style side menu presentation and dismissal
* Uses native UIKit components with **no CocoaPods or Swift Package Manager dependencies**
* Focused on clean, reusable, and dependency-free implementation

### Key Technologies

**Swift · UIKit · UITableView · UIViewController · Auto Layout**

### Dependencies

**No third-party libraries**
**No CocoaPods**
**No Swift Package Manager**
